# Aarast / اعّرست

A Yemen-first wedding planning app: wedding money, tasks, guests, family sharing, and a provider marketplace. The app tracks money and never moves it.

## Stack

| Part | Tech | Folder |
|---|---|---|
| Mobile | Flutter | `mobile/` |
| API | NestJS, Prisma, PostgreSQL | `backend/` |
| Admin | React, Vite, TypeScript | `admin-web/` |
| Hosting | AWS for the app, OpenWA for WhatsApp codes | `deploy/` |
