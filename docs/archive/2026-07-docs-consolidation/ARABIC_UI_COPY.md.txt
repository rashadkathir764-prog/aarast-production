# Aarast Arabic UI Copy

This document contains standard, simple Yemeni-friendly Arabic text used across the application. It avoids overly formal Arabic and unprofessional slang.

## General Actions
- **Next**: التالي
- **Skip**: تخطي
- **Start Now**: ابدأ الآن
- **Save**: حفظ
- **Cancel**: إلغاء
- **Edit**: تعديل
- **Delete**: حذف
- **Add**: إضافة
- **Confirm**: تأكيد
- **Close**: إغلاق

## Authentication
- **Login**: تسجيل الدخول
- **Create Account**: إنشاء حساب
- **Phone Number**: رقم الهاتف
- **Email**: البريد الإلكتروني
- **Password**: كلمة المرور
- **Confirm Password**: تأكيد كلمة المرور
- **Forgot Password?**: نسيت كلمة المرور؟
- **Don't have an account?**: ليس لديك حساب؟
- **Already have an account?**: لديك حساب بالفعل؟

## Dashboard & Navigation
- **Overview (Home)**: نظرة عامة
- **Expenses**: المنصرفات
- **Debts**: الديون
- **Tasks**: المهام
- **Settings**: الإعدادات
- **Timeline**: الجدول الزمني
- **Installments**: الأقساط

## Financial Terms (Clear & Simple)
- **Estimated Budget**: الميزانية التقديرية
- **Total Amount**: المبلغ الإجمالي
- **Paid Amount**: المبلغ المدفوع
- **Remaining Amount**: المبلغ المتبقي
- **Creditor (Person owed)**: الدائن / صاحب الدين
- **Next Installment**: القسط القادم
- **Due Date**: تاريخ الاستحقاق
- **Category**: الفئة (مثال: القاعة، الضيافة، الملابس)

## Wedding Plan Setup
- **Groom Name**: اسم العريس
- **Bride Name**: اسم العروس
- **Expected Wedding Date**: تاريخ الزفاف المتوقع
- **Days Remaining**: باقي على الزفاف (يوم)

## Empty States & Feedback
- **No expenses yet**: لا توجد منصرفات بعد
- **No tasks yet**: لا توجد مهام بعد
- **Saved successfully**: تم الحفظ بنجاح
- **Error occurred**: حدث خطأ، يرجى المحاولة مرة أخرى
- **Are you sure you want to delete this?**: هل أنت متأكد من حذف هذا العنصر؟

## Privacy (Future)
- **Members and Permissions**: الأعضاء والصلاحيات
- **Invite Member**: دعوة عضو
- **Private (Only you can see this)**: خاص (أنت فقط من يمكنه رؤية هذا)
- **Financial Visibility**: صلاحية رؤية الأمور المالية
