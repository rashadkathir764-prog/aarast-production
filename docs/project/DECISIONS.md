# القرارات السارية

هذا السجل يذكر القرارات السارية فقط، كل قرار في سطر. أي قرار قديم غير مذكور هنا فهو ساقط.

**النص الكامل:** كل قرار بتفاصيله موجود في تاريخ git عند `2492d244` في `docs/project/DECISIONS.md`. ارجع إليه فقط إذا احتجت تفصيل قرار بعينه، لا لتعرف الوضع الحالي.

**قاعدة الإضافة:** القرار الجديد سطر واحد هنا، بالرقم التالي، ويذكر من قرره ومتى.

## القانون والمال

| الرقم | القرار |
|---|---|
| قانوني | التطبيق يتتبع المال فقط. لا دفع داخل التطبيق، ولا محفظة، ولا تحصيل عربون، ولا تمويل. هذا يحتاج شريكًا ماليًا مرخصًا |
| قانوني | الديون تُسجل كمصدر فلوس من نوع سلفة مع جدول سداد، ومصادر الفلوس يراها صاحب الخطة فقط |
| تسمية | كلمة «أقساط» ممنوعة في الواجهة |
| C1 | المهر خارج ميزانية العرس. للعريس فلوس خارجة، وللعروسة فلوس داخلة |
| C2 | أرقام المال من الخادم فقط، والجوال لا يحسب الناقص |
| C12 | دين ما بعد العرس = السلف الباقية + الاتفاقات غير المدفوعة |
| C15 | حذف البند يرجع مخصصه للاحتياط |
| D41 | العربون دفعة عادية في المال، ولا يوجد تأكيد استلام من المزود، ولا قاعات أو فرق بأسمائها في الإصدار الأول |
| D51 | الظهور المميز يُدفع خارج التطبيق وتفعّله الإدارة يدويًا، وعند العرسان يظهر أنه مدفوع |
| D55 | المهر مال للخطة خارج ميزانية العرس، وجهته تتبع نوع الخطة |
| D59 | قراءة واحدة لأرقام المال، ودفعة غير صاحب الخطة لا تُخصم من «معك» |
| D60 | كم حجز في اليوم رقم يحدده المزود، والمتفق والمدفوع والباقي مصدرها واحد |
