# القرارات السارية

هذا السجل يذكر القرارات السارية فقط، كل قرار في سطر. أي قرار قديم غير مذكور هنا فهو ساقط.

**النص الكامل:** كل قرار بتفاصيله موجود في تاريخ git عند `2492d244` في `docs/project/DECISIONS.md`. ارجع إليه فقط إذا احتجت تفصيل قرار بعينه، لا لتعرف الوضع الحالي.

**قاعدة الإضافة:** القرار الجديد سطر واحد هنا، بالرقم التالي، ويذكر من قرره ومتى.

## القانون والمال

| الرقم | القرار |
|---|---|
