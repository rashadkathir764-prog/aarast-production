# قالب المسار: العريس والعروسة

قرار رشاد (2026-10-19): **مسار العروسة هو مسار العريس نفسه، شاشة بشاشة.** نفس الـ119 شاشة، ونفس الترتيب، ونفس التبويبات، ونفس الحالات، ونفس الأرقام. الفرق في ثلاثة أشياء فقط:

1. **الألوان**
2. **الخطاب**
3. **التصنيفات**

ما فيه شاشة تخص العروسة لوحدها، ولا شاشة تختفي عندها، ولا خصوصية مختلفة.

## 1. الألوان

| | العريس | العروسة |
|---|---|---|
| اللون الأساسي | فيروزي `#0B6E69` | وردي `#B4536A` |
| الغامق | `#064B47` | `#7A2E45` |
| الفاتح | `#DCEFEC` | `#F8E4EA` |
| ليل سماء العرس | `#0E2A33` | `#2E1624` |

ألوان الأقسام (المهام زعفراني، الضيوف بنفسجي، المزودين سماوي) واحدة للاثنين.

## 2. الخطاب

- العريس بصيغة المذكر، والعروسة بصيغة المؤنث: «سجّل» تصير «سجّلي»، و«تقدر» تصير «تقدرين»، و«دفعت» تصير «دفعتِ».
- الكلام اللي على لسانها هي للتطبيق يبقى مثل ما هو: «جهّز خطتي»، «احفظ خطتي برقم جوالي».
- **الخطاب يتبع اللي يقرأ، والألوان والتصنيفات تتبع الخطة (D55):** العروسة لما تساعد في خطة العريس تشوف ألوانه وبنوده وتنخاطب بالمؤنث، والعريس في خطة العروسة يشوف الوردي و«الضيفات» و«الصالة» وينخاطب بالمذكر. جنس اللي يقرأ من حسابه (عريس أو عروسة)، وإلا من دوره في الخطة، وإلا من الخطة نفسها. وتنبيهات الخادم تنكتب لكل واحد بجنسه.

## 3. التصنيفات

| | العريس | العروسة |
|---|---|---|
| الطرف الثاني | أهل العروسة | العريس |
| المهر | سلّمت، يسلّمه | استلمتِ، تستلمه |
| مناسبات الأسبوع | السمرة، المقيل، الزفاف | الحفلة، النسمة، الزفة |
| المكان | القاعة (قاعة سبأ)، الديوان | الصالة (صالة الياسمين) |
| بند القات | القات، المقوّت | البخور، العطّار |
| بند الفرقة | الفنان والفرقة | المزينة والنقاشة |
| بند اللبس | بدلة العريس | فستان الزفة |
| المصور | المصور، استوديو | المصورة |
| الدفتر | دفتر الرفد، رفدك | دفتر الهدايا، هديتها |
| المساعد | صالح أخوي | نورة أختي |
| الوالد | الوالد | الوالدة |
| الضيوف | ضيوف، مدعو، أكدوا | ضيفات، مدعوة، أكدن |

| الأيقونات | الفرقة 🎵، القات 🍃 | المزينة ✨، البخور 🔥 |

## كيف ينبني

في التطبيق: حقل "نوع الخطة" (عريس أو عروسة) يختار الثيم وملف النصوص (صيغة المذكر أو المؤنث)، والتصنيفات بيانات في الخادم حسب نوع الخطة.
