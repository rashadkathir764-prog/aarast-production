# قالب المسار: العريس والعروسة

مسار واحد بنفس الشاشات والتبويبات ودورات الحياة، و"قالب" يحدد الفرق. قرار رشاد (2026-10-19): مسار العروسة نفس مسار العريس بالكامل، والاختلاف في الألوان والتصنيفات وما يلزم.

## وش في القالب

| | العريس | العروسة |
|---|---|---|
| الألوان | فيروزي، وسماء العرس الفيروزية | وردي ولؤلؤ، وليل بنفسجي بحبال لمبات |
| صيغة الكلام | مذكر: اكتب، سجّل | مؤنث: اكتبي، سجّلي |
| المهر | يطلع منه: يسلّمه لأهل العروسة | يدخل لها: تستلمه، وهو مصدرها الأول |
| المناسبات | السمرة، المقيل، الزفاف | الحمام، الذبال، النقش، الحفلة، النسمة، الزفة، ثم الثالث والشكمة والسابع |
| البنود الجاهزة | القاعة، الضيافة، القات، الغداء، الزينة، الفنان، التصوير | الذهب، الجهاز، الفساتين، الصالة النسائية، الضيافة، المزينة، النقاشة، المصورة، الحمام |
| المهام الجاهزة | عقد القران وأوراقه، المقوّت، الزينة، الألعاب النارية | البروفة، النقاشة، المزينة، الحمام، قائمة الجهاز |
| أقسام المزودين | قاعات، فرق، قات، ضيافة، زينة، ألعاب نارية | صالات نسائية، مزينات، نقاشات، مصورات، فساتين، ذهب، مفارش، حمامات |
| الدفتر | دفتر الرفد | دفتر الهدايا (فلوس وذهب) |
| الخصوصية | عادية | مشددة من البداية: بصمة، صور ما تطلع، تنبيهات بدون تفاصيل |

## ميزات صارت للاثنين

- **الذهب بالجرام والعيار:** قسم كامل عند العروسة، وعند العريس لو أضاف الذهب.
- **لبس لكل مناسبة:** فستان لكل يوم عند العروسة، وعند العريس بدلة الزفاف والثوب والجنبية للسمرة ولبس المقيل.
- **قائمة بالأنواع:** الجهاز عند العروسة، وأغراض البيت عند العريس لو حب.
- **شارة "نسائي"** خاصية في المزود نفسه، تظهر في مسار العروسة.

## الخادم

- حقل "نوع الخطة" (عريس أو عروسة) يحدد القالب، والقالب بيانات في الخادم (المناسبات والبنود والمهام والأقسام) مو كود.
- المهر عند العروسة مصدر دخل (`FundingSource`) مرتبط بالاتفاق، وعند العريس بند (`WeddingCost`).
- وحدة "جرام" وعيار للبنود والهدايا الذهبية.
- خاصية "نسائي" للمزود، ولبس لكل مناسبة مرتبط بالمناسبة.
