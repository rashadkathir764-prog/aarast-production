## 4. ميزات جديدة مطلوبة

| # | البند | معيار القبول | الحالة |
|---|---|---|---|
| 4.1 | **مناسبات العرس المتعددة**: الحناء، الزفاف، المقيل، الصبحية، مع رجال ونساء | كل مناسبة لها تاريخ ومكان وضيوف وتكاليف ومزودون | ⬜ |
| 4.2 | **مصادر التمويل**: مدخرات، مساعدة الأهل، رفد ونقوط، دين | "كم باقي" = الموارد − الالتزامات، ويُعرض بوضوح | ⬜ |
| 4.3 | **الديون**: لي وعليّ، مع جدول سداد وتذكير | خاصة افتراضياً، ولا يراها مشارك بدون إذن مستقل | ⬜ |
| 4.4 | إيصالات ومرفقات للتكاليف والدفعات والديون | تصوير الإيصال وربطه، وتطبَّق عليه نفس خصوصية المال | ⬜ |
| 4.5 | "مين يدفع" لكل تكلفة | العريس، العروسة، الأهل، أو عضو مشارك، مع تصفية حسبه | ⬜ |
| 4.6 | **الحجز بدون دفع** + تقويم إتاحة المزود | العرض المقبول يتحول إلى طلب حجز، ثم تأكيد المزود، ثم "محجوز"، ولا حجز مزدوج لنفس التاريخ | ⬜ |
| 4.7 | دعوات الضيوف الرقمية + تأكيد الحضور | بطاقة دعوة تُرسل عبر واتساب، والضيف يؤكد من صفحة ويب، والحالة تتحدث | ⬜ |
| 4.8 | تنبيه تجاوز الميزانية لكل بند | إشعار عند تجاوز البند المخطط | ⬜ |
| 4.9 | قوالب مهام وبنود يمنية | تشمل المهر، والشرط، والشبكة، والكسوة، والقات والمقيل، والولائم، والفنان، والزفة، والمخدرة، والنقش، والشقة، والأثاث، وشهر العسل | ⬜ |
| 4.10 | خصوصية بين العريس والعروسة | دور "شريك" بصلاحيات مالك، وبنود خاصة لكل طرف لا يراها الآخر | ⬜ |
| 4.11 | بطاقة المزود الكاملة | نطاق السعر، "آخر تحديث للسعر"، شارة "موثّق"، زر واتساب، الموقع، "يرد عادة خلال…" | ⬜ |
| 4.12 | **المساعد الذكي** | يبني خطة، ويقسم الميزانية، ويقارن العروض، ويقترح بدائل، ويذكّر بما نُسي، ويكتب رسالة تفاوض. لا يخترع أسعاراً، ويطلب موافقة صريحة على مشاركة البيانات | ⬜ |
| 4.13 | تأجيل العرس أو إلغاؤه | تحديث كل التواريخ والتذكيرات، وإبلاغ المزودين، وتسجيل المبالغ المستردة | ⬜ |
| 4.14 | تغيير رقم الجوال | مسار آمن لنقل الحساب لرقم جديد | ⬜ |
| 4.15 | قفل التطبيق برمز أو بصمة | اختياري، ويُطلب عند فتح التطبيق | ⬜ |
| 4.16 | مشاركة ملخص الميزانية والمهام عبر واتساب | صورة أو رابط قراءة فقط، بدون كشف ما هو خاص | ⬜ |
| 4.17 | تذكيرات مرحلية | قبل العرس بشهر وأسبوع ويوم، وقبل كل دفعة وكل حجز | ⬜ |
| 4.18 | مزود يضيفه الأدمن ثم يطالب بملفه | الأدمن ينشئ الملف، والمزود يستلمه برقم جواله | ⬜ |
| 4.19 | إحصائيات المزود | مشاهدات، وطلبات عروض، ونسبة قبول، وحجوزات | ⬜ |
| 4.20 | باقات المزودين والظهور المميز | تُفعَّل يدوياً من الأدمن، بدون تحصيل مالي آلي | ⬜ |
| 4.21 | مؤشرات النجاح للأدمن + تقرير أسعار السوق | مستخدمون نشطون أسبوعياً، ومصاريف لكل مستخدم، وتحويل العروض إلى حجوزات، ومتوسطات أسعار مجهولة الهوية حسب المنطقة | ⬜ |
| 4.22 | أداة استيراد مزودين للأدمن | رفع ملف CSV لإضافة مزودين دفعة واحدة | ⬜ |

## 7. خارج V1 بقرار قانوني 🚫

يستلزم شريكاً مالياً مرخّصاً في اليمن (`wedding.md` الأقسام 8 و9 و15). يُسلَّم التصميم جاهزاً للربط لاحقاً.

- الدفع داخل التطبيق.
- المحفظة.
- العربون المالي.
- التقسيط والتمويل عبر طرف ثالث.
- التحصيل الآلي للاشتراكات.

**التطبيق يتتبع المال بالكامل، لكنه لا يستلمه ولا يحرّكه.**
