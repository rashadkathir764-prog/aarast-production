# سجل الممارسات

## كيف يُقرأ

**الحالة في اعّرست** واحدة من خمس:

| الحالة | معناها |
|---|---|
| ✅ موجودة | موجودة في اعّرست |
| 🔧 تحتاج تحسينًا | موجودة وتحتاج تحسينًا |
| 🧩 ناقصة | ناقصة وتحتاج استكمالًا |
| 💡 فرصة | غير موجودة، وفرصة تطوير |
| ⛔ غير مناسبة | غير مناسبة لاعّرست |

**النطاق:**
- **المهمة الحالية:** تنفذ في خطة 2026-11-26، ويُذكر القسم الذي تنفذ فيه.
- **مستقبل:** مكانها [OPPORTUNITIES.md](OPPORTUNITIES.md).

**التحديث:** حين تُنفذ فكرة أو يتغير حالها، تُحدَّث خانتها هنا، ويُكتب معها رقم القرار أو التدقيق.
