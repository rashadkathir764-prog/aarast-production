# مشي المسارات في التطبيق الحقيقي (Journey Walks)

Snapshot date: 2026-10-25 · commit المشي: `db0270e7` (الجوال والخادم) · البيانات: `prisma/demo-seed.ts` بتاريخ اليوم

هذا الملف يشرح أداة واحدة تتكرر عند كل تسليم: تفتح **التطبيق الحقيقي** (`lib/main.dart` نفسه، بنفس
المزودات و`ApiClient`) على ويندوز، وتدخل بحسابات التجربة مثل ما يدخل الناس، وتمشي كل مسار بالضغط،
وتصوّر كل شاشة، وتتأكد من الأرقام والجمل اللي لازم يشوفها المستخدم. كل خطوة نتيجتها **ناجحة** أو
**فاشلة** مع السبب والصورة. الخطوة الفاشلة هنا = مشكلة حقيقية في التطبيق أو البيانات، مو خطأ في الأداة.

The walks boot the real app against the real local API, sign in with the demo
accounts, tap through each journey, save a PNG and the visible text of every
screen, and assert what a user must see. A failing step is a finding.

## إعادة التشغيل (How to rerun)

1. **الخادم المحلي:** من `backend`:
   ```powershell
   npx prisma migrate deploy        # يطبق الهجرات المعتمدة فقط
   npm run start:dev                # المنفذ 3215 من .env
   ```
   تأكد إنه شغّال بالكود الأخير. يوم 25 أكتوبر كان على 3215 خادم من 23 أكتوبر (كود قديم)، فشغّلنا
   نسخة ثانية بالكود الأخير على 3216 (`$env:PORT=3216; npm run start:dev`) ومشينا عليها.
2. **البيانات:** من `backend` (كلمة السر من عندك، 12 حرف أو أكثر، ولا تنحفظ في المستودع):
   ```powershell
   $env:DEMO_PASSWORD='<كلمة سر التجربة>'
   $env:DEMO_SEED_TODAY='<تاريخ اليوم، مثل 2026-10-25>'
   npx ts-node prisma/demo-seed.ts
   ```
   **ليش تاريخ اليوم مو 2026-10-17:** التطبيق يقرأ ساعة الجهاز الحقيقية. لو ثبّتنا البيانات على 17
   أكتوبر والجهاز في 25، تصير 4 مهام متأخرة بدل وحدة، ودفعة القاعة متأخرة بدل «بعد 5 أيام»، وعرض
   الاستوديو منتهي بدل المقارنة. بتاريخ اليوم تطلع نفس حالات التصاميم (مهمة متأخرة وحدة، الدفعة
   بعد 5 أيام، عرضين للمقارنة). اللي يختلف بس العدّاد (88 يوم بدل 96) لأن موعد العرس ثابت 21 يناير.
3. **المشي:** من `mobile`، كل ملف لوحده (كل ملف يفتح التطبيق مرة):
   ```powershell
   flutter test --no-pub integration_test/journeys/groom_walk_test.dart -d windows `
     --dart-define=AARAST_API_BASE_URL=http://127.0.0.1:3215 `
     --dart-define=DEMO_PASSWORD=$env:DEMO_PASSWORD `
   ```

   والباقي بنفس الأمر: `bride_walk_test.dart`، `participant_saleh_walk_test.dart`،
   `participant_father_walk_test.dart`، `provider_studio_walk_test.dart`،

4. **النتيجة:** في `AARAST_WALKS_DIR\<المسار>\`: `NN_<الشاشة>.png` و`NN_<الشاشة>.txt` (النص الظاهر)
